# Vídeos do site

A página Como utilizar incorpora um vídeo de demonstração que espera este
arquivo:

    videos/demonstracao.mp4

Esse arquivo nunca foi publicado no repositório. No site original o caminho
apontava para uma pasta local da máquina de quem montou a página, então o
vídeo só aparecia para essa pessoa.

Coloque o arquivo aqui com esse nome exato e o player passa a funcionar,
sem precisar mexer no HTML.
